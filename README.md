# Baltic Sea Vista

Real-time vessel tracking application for monitoring maritime activity in the Baltic Sea region, with focus on shadow fleet detection.

## Features

- Interactive map with vessel markers
- Real-time AIS data integration
- Shadow fleet identification
- Vessel list with click-to-navigate

## Tech Stack

- Next.js 16 / React 19
- Mapbox GL JS
- Tailwind CSS v4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Create `.env.local`:

```
NEXT_PUBLIC_MAPBOX_TOKEN=your_token
DATALASTIC_API_KEY=your_key
```
